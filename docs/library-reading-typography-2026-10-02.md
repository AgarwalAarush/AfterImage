# Library reading typography

The Subjects font refinement initially left Library notecards on the older Newsreader prose overrides. Library now consumes the existing `subject-prose` preset through CSS Module composition in `paper-reading.module.css`, sharing its sans-serif font, line height, paragraph rhythm, and heading treatment instead of duplicating those rules. Both readers use the same self-hosted `--font-sans` asset and `--recall-font-size` convention: 17px desktop prose and the existing 15px narrow-screen compatibility scale. Library introductions use 16px sans-serif text with 1.65 line height, and recall paragraphs have a maximum 68ch measure.

The Library reader scopes the legacy serif alias to the shared sans-serif so summary, equation explanations, walkthrough cells, and quiz questions use the same family. The existing shared quiz component and each reader's separate progress storage remain intact. Diagram renderers, source content, scientific review, stored reading kits, and Subjects presentation sources are unchanged. The scoped module remains inert on Subjects routes, including after navigating from a Library paper. This is a web-only presentation change.
