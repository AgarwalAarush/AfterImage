# Subject reader refinements

Subject lessons use the library paper reader's desktop type scale: 16px Newsreader body at 1.85 line height, 44px title, 17px summary, 27px section headings, and 16px sans-serif study headings. Quiz choices use the existing paper quiz's 14px sans-serif treatment and native radio controls. Incorrect selected answers and the correct answer receive separate feedback surfaces; retry clears the previous choice.

The reader instance is keyed to the current reviewed lesson and mechanism digests. A changed lesson or storyboard starts its controls from a valid initial state, avoiding a stale beat index after a shorter storyboard replaces the current one. Browser-saved quiz progress remains tied to the lesson digest and is restored when only its diagram changes.

Walkthrough introductions lead into the first diagram row with a 40px gap: 16px of component spacing and a 24px SVG inset. The previous 80px SVG inset compounded paragraph margins into a 90px gap. The shared layout keeps room for routed connectors without a large empty band above the first object. This changes the mechanism renderer fingerprint and requires renewed visual acceptance for each stored walkthrough.

Single-identity modules use a centered horizontal content group: the title and detail share one left edge, and the identity sits directly beside those lines at their vertical center. The token no longer floats at the far card corner or changes only the title's center. This preserves the compact 60px encoder and stable object geometry across beats; the renderer change requires fresh visual acceptance of all fourteen walkthroughs before release.

`SubjectProse` accepts dollar and TeX parenthesis/bracket delimiters without rewriting literal code. Inline prose renders mathematical labels without nested paragraph elements. Inline equations stay together across KaTeX internal operator spans. Section headings suppress an authored numeric prefix in presentation, since the contents rail already supplies its own numbering. KaTeX remains untrusted, bounded, and HTML is skipped. Background chips, contents numbers, and quiz numbers have explicit classes; styles never target all descendant spans because KaTeX generates its own span tree. Math rendering has regression coverage for labels, display equations, code preservation, and raw HTML.

`scripts/refine-subject-prose.ts` is an explicit editorial action for already published subject lessons. Its default scope edits only sections associated with figures and replaces repetitive disclaimer lists with a natural explanation of the example's calculation, assumptions, and relationship to the paper's actual mechanism. A named lesson may explicitly select sections using `--sections s4,s7` and remove an obsolete figure using `--drop-figure fig-memory`; the figure's single section anchor is cleared and at least one authored experiment remains required. Source/claim relationships, ledger statements, unselected chapters, and quiz answers remain unchanged. Claims recover their exact quotations only from unchanged private draft ledgers, and saved source digests must match the publication.

A current source-reviewed mechanism can be rebound after prose-only publication only when every claim identity/statement and source URL/hash/provenance remains identical. Its semantic structure and digest stay fixed and are revalidated against the new parent; visual approval resets to `source-passed`. A new desktop review bound to the new parent and current renderer is required before the ordinary reader serves it. Concurrent mechanism or lesson edits abort publication.

Run `node --import tsx scripts/refine-subject-prose.ts --id <identity>` for a selected lesson or `--all` for the currently published set. `--no-publish` retains a reviewed candidate privately. Concurrency defaults to one and may be explicitly bounded to three. Candidate drafts, diagnostics, source excerpts, and independent review reports stay under ignored `.artifacts/subjects/prose-refinements/`. Structural evidence checks, complete math validation, and independent science/teaching/experiment/quiz review all must pass before atomic publication. A private review binding records the candidate, source, baseline, and experiment implementation digests. Changes to the published lesson or experiment implementation during review abort the edit, and a failed refinement leaves the current lesson untouched. Browser and visual acceptance remain separate from these semantic checks.

## Appendix-backed refinements

The reader suppresses a leading body heading only when it matches the already rendered section title (case, whitespace, and the existing numeric-prefix normalization). Different or later headings and fenced code remain unchanged. This is display-only and does not alter source-reviewed lesson content or its publication digest.

`refine-subject-prose.ts --id <id> --sections <ids> --appendix-ids <ids>` can supplement an existing reviewed lesson with bounded appendix evidence from its captured public arXiv HTML (`.artifacts/subjects/<id>/appendix-source.html`). Existing primary excerpts must first match published hashes. Appendix IDs must resolve in the deterministic extractor; URLs and capture hashes are bound to the new review. The complete lesson still requires independent source, teaching, experiment, quiz, and math checks before publication. A changed source ledger does not receive a mechanical mechanism rebind: the old sidecar becomes unreadable until independently reviewed against the new parent.

The v5 HTML extractor appends appendix evidence after main sections, preserving main-section identities and the existing excerpt/total-source budgets. This prevents a missing capture of Appendix C from being presented as a limitation of TRPO itself. A captured source alone is not a publication approval.

`--candidate-file .artifacts/subjects/<candidate>.json` reviews a locally authored complete candidate first, avoiding an unnecessary editing model call. Host checks constrain changes to selected sections and preserve all other relationships, figures, quiz answers, and claims. An explicit appendix capture additionally permits corrected conditions/evidence for an unchanged claim assertion only when it keeps its old source references and adds the captured appendix. This option still performs every independent full-lesson review and publication guard; it cannot approve a candidate by itself.

`--drop-figures f-noise,f-scaling` explicitly removes multiple obsolete controls while retaining at least one authored experiment. Duplicate/unknown figure identities and a zero-figure result fail validation. Whisper's completed local refinement replaced the generic Gaussian and invented loss controls with actual acoustic encoding, token grammar, comparative-result conditions, and long-form decoding teaching; its attention contract, claim/quiz/source ledgers, and mechanism geometry stay intact. Its complete lesson passed independent review and its rebound walkthrough passed desktop visual acceptance.
