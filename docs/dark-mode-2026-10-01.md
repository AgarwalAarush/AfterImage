# Dark appearance

AfterImage now offers System, Light, and Dark in the header and on the login
screen. System is the default. A local `afterimage-theme` preference persists
across reloads and tabs; it contains no library data and makes no API writes.
System changes update the open page only when System is selected. If browser
storage is unavailable, appearance still works for the current page.

The root layout initializes appearance before the first paint. Only the root
theme attribute suppresses hydration differences; interactive controls still
hydrate normally. `globals.css` keeps the original light colors as fallbacks;
`theme.css` supplies warm charcoal surfaces, readable text, and semantic
accent/status colors. Existing desktop layout and responsive behavior stay in
place. Embedded original PDFs retain the PDF viewer's own appearance.

`diagram-theme.ts` adapts colors at the browser presentation boundary for
hand-authored diagrams, legacy generated scenes, flow-v2 scenes, and study
figures. It preserves text, topology, geometry, arrow routing, explicit opacity attributes, and numeric
heat-scale ordering. The worker continues generating and reviewing the same
deterministic SVGs; no stored scenes or review gates change. Quantitative heat
cells keep white labels on the stronger values. Diagram downloads embed the
computed selected palette, background, and fonts so standalone files remain
readable outside the site.

Validation covers saved/system appearance, light-mode fallbacks, desktop
reader/library/Documents/assistant/palette views, generated and authored SVGs,
quantitative figures, and standalone SVG exports. A web-only release is
sufficient; no bridge or worker update is required.

Local acceptance on October 1: all 74 tests passed, TypeScript and the production
build passed, and browser checks covered persistence, system changes, tab sync,
desktop reader/assistant/command palette/login/Documents, narrow header
compatibility, generated scene palettes, heatmaps, landscapes, curves, and a
standalone SVG download rendered independently. Temporary document test content
was removed. This records local verification; it does not assert a deployment.

Release integration rebased onto the current scientific-diagram release at
`4c3b90b`. The combined 108-test suite and production build passed. New gauge
tracks retain their color alpha, and named-white arrow underlays follow the dark
canvas. Additional browser checks covered the scientific illustration fixtures.
Browser verification artifacts and logs are excluded from Vercel uploads.
