# Original Subjects library — October 1, 2026

AfterImage now has a separate Subjects catalog and lesson reader. The catalog maps all 100 live entries found in intuitivepapers.ai’s library on October 1 to eight topic groups and primary research. The reference site supplies coverage and attribution links; its article bodies, scripts, and artwork are not imported. Lessons are original explanations generated from the cited primary papers, with authored interactive computations.

This is local work until a compatible web release is deployed and verified. All 100 lessons now pass the final publication audit. Available content is determined from the validated lesson files, rather than the private batch progress log.

## Product and storage boundaries

- `/subjects` lists lightweight metadata, search results, and topic filters. Only an explicitly opened lesson sends its body to the browser. Lesson links disable prefetch.
- `/subjects/[id]` requires the existing owner authentication before reading content. Unknown, missing, invalid, or mismatched lesson files return not found.
- Subjects bypass paper-library background polling, as Documents already does. Opening the paper command palette remains an explicit library action.
- Source-reviewed lessons are build-bundled JSON under `src/content/subjects/lessons/`; they are separate from the authoritative macserver SQLite paper library and uploaded documents. No storage-bridge actions or worker-queue schema change is involved.
- Reading progress and quiz answers are browser-local and keyed by the content fingerprint. They are not fabricated paper-library reading history.
- Exact source excerpts, drafts, model diagnostics, repair findings, and review reports remain in ignored `.artifacts/subjects/`. Published claims contain original statements, conditions, source IDs, and source links; they omit the verbatim evidence passages used by the private audit.
- The Next file-tracing configuration includes the lesson JSON files. Adding lessons requires another web build/release; it does not update an already deployed build.

## Source and teaching pipeline

`sync-subject-catalog.py` records titles, topics, reference URLs, and primary arXiv identities. It does not extract the reference explainer’s body. Catalog identities are allowlisted before any file read.

`generate-subject-lessons.ts` imports each primary paper through the existing research-source extractor. Abstract-only extraction cannot qualify for a full lesson. A draft has prerequisites, learning objectives, a source-supported claim ledger, substantive mechanism sections and worked examples, two or three bounded interactive experiments, and three questions with explanations for every choice.

The publication schema accepts one to three authored experiments. Generation continues to target two or three; an explicit editorial action may remove an unrelated prerequisite figure after full independent review while retaining at least one experiment. Zero-experiment lessons remain invalid until the main publication contract requires a reviewed mechanism sidecar.

The AlphaZero audit exposed a source acquisition defect: its unsectioned main article was omitted while its sectioned supplementary methods were retained. The shared HTML extractor now retains unsectioned scientific body paragraphs, equations, tables, and captions as `main-text` excerpts before sectioned material. Existing section identities stay stable; nested section blocks are not duplicated, abstract and bibliographic/acknowledgement material are excluded, and the same excerpt and total-source bounds apply. Refresh affected evidence before generation; do not treat an incomplete methods-only context as a complete mechanism source.

Local checks validate IDs and source relationships, exact private evidence passages, figure placement, distinct quiz options, word count, complete summaries, and KaTeX in every rendered field. The math parser and reader share delimiter normalization, including conventional TeX delimiters. They preserve literal code and reject unclosed equations or control characters. An underscore-to-hyphen figure reference may be repaired only if it matches an already declared figure; other unknown references remain invalid.

An independent model review checks science, teaching, experiment interpretation, and all quiz choices against primary evidence and the exact authored experiment contracts. Passing requires all four checks to pass with no findings. Repairs replace only affected fields, preserving correct content and claim identities, then repeat the complete checks. Each patch carries its actual field bound; a 350-character evidence limit is distinct from a long section-body limit, and an invalid patch cannot replace the prior valid candidate. Citation corrections are restricted to supplied primary source IDs. Short prerequisite and objective labels have generous headroom below output bounds, avoiding clipped prose. Saved drafts and sources support explicit resumption.

Published content gets a SHA-256 fingerprint after private audit excerpts are removed, binding the original explanations to source URLs, evidence hashes, capture/extraction provenance, and the lesson identity. The server recomputes that fingerprint and checks the current math before accepting a lesson. These checks catch stale or malformed content; a model review is not evidence that every scientific statement is infallible.

## Reader and figures

Reader typography follows the existing paper pages: Newsreader body text at 16px and 1.85 line height, 44px titles, 17px summaries, 27px section headings, and the paper reader’s inline/display equation scale. Prerequisite chips style only their outer element, so KaTeX’s nested spans never become nested chips. Shared control styling remains in `ui.css`.

The experiments calculate displayed values from fixed illustrative inputs. Axes stay fixed while a parameter changes. Probability rows normalize to one; routing loads derive from selected connections; memory distinguishes live, padding, and free slots; numerical trajectories connect actual computed values. Relationships use topology rather than unrelated decorative diagrams. SVG colors resolve from browser theme variables at presentation time.

The FlashAttention lesson now teaches online softmax with a native step-by-step accumulator: changing tile width or traversal order changes intermediate maximum/normalizer/value sums while preserving exact dense attention. The Geometry lesson has an original rotatable 3D RMS-shell instance with visibility controls and an inner-noise slider. Its prose distinguishes ideal surfaces at RMS radii from actual Gaussian draws and relates the geometry to the paper’s codimension assumptions. These changes passed full source/math/teaching/quiz review; desktop browser acceptance remains separate. `refine-subject-figures.ts` uses an explicit target map for the authorized FlashAttention, Geometry, NeRF, SmoothQuant, and Mistral replacements. It retains existing public content until the update passes and rejects publication if the parent bytes changed during review.

Playback is an explicit action. It pauses on manual input, supports reset, stops advancing while hidden/offscreen, and starts paused under reduced motion. Every display also provides a numeric inspection table. Repeated captions and warning paragraphs below figures are removed; useful units, assumptions, and interpretation belong in the lesson prose. The control’s question and computed result remain beside the drawing.

Development-only `/subjects/review` renders the authored experiment families for browser acceptance; it is unavailable in a production build. Native-size rendering checks cover parameter extrema, topology, finite coordinates, and bounded labels. Actual desktop browser review remains required before release, including both themes, controls, math, quiz feedback, and per-lesson figure placement. Passing content review alone must not be described as a completed visual review.

## Running the explicit batch

```sh
python3 scripts/sync-subject-catalog.py
npm run subjects:generate -- --all --resume-defects --concurrency 3
```

Use `--id <catalog-id>` for a selected lesson. Separate authorized recovery batches use `--status-file <filename>` and `--exclude <comma-separated-ids>` to avoid overwriting the main progress projection. The canonical availability check reads valid lesson files; private status logs can be stale after interruption. Generation is never triggered by hover, prefetch, page load, or search.

`--refresh-evidence` reacquires primary excerpts instead of reusing a cached context. Private evidence records its extractor version and capture time; outdated caches refresh automatically. A newly recovered main body or explicit fresh-evidence request begins a fresh draft and its own bounded review cycle rather than repairing a candidate built against materially incomplete excerpts. Otherwise resumption selects the latest valid saved candidate, including recovery candidates, and rechecks its complete evidence mappings against refreshed sources.

For PDF extraction, set `AFTERIMAGE_PYTHON` to an existing Python runtime with the repository’s source-extraction dependencies. The signed-in generation transport uses the existing configured model; it does not install software or change account settings.

## Paper-specific walkthroughs

Optional mechanism walkthroughs supplement the numerical primitives with actual paper-specific state and information flow. They use bounded symbolic entities, stable object identities, retained collections, source-grounded relationships, and discrete explanation beats. The model supplies semantic state only; host code composes glyphs and reuses the obstacle-aware route generator. A source-passed sidecar remains unavailable to ordinary readers until a desktop visual review is bound to its content, parent lesson, and renderer fingerprints. See [mechanism generation](subject-mechanisms-2026-10-01.md).

The source acquisition audit also found that some arXiv papers put their main argument directly in the document, outside section wrappers. The extractor now retains those scientific blocks with separate bounded main-text citations, preserving stable section identities and avoiding duplicate nested paragraphs. This fixes the missing AlphaZero mechanism and improves future paper processing; existing paper kits are not silently regenerated.

## Exact primary passage selection

The generation pipeline now separates original teaching prose from its private evidence bindings. Draft models write scientific statements and source IDs without reproducing quotations. Host code segments the public primary excerpts into deterministic, literal 20–350-character ranges; an isolated selector chooses a supplied passage ID for each claim, scoped to that claim's declared primary citations. The binder records the original range and exact text privately. It cannot create a quotation, change a scientific statement, or redirect a citation. Prose repairs no longer accept model-authored quote replacements. Claim patches address stable ledger IDs rather than array positions: this prevents a finding about c11 from accidentally changing the twelfth claim. A bounded claim-link patch may correct section/figure/quiz references only to existing declared claim identities, followed by the same independent scientific review; it cannot create claims or change their IDs.

Literal matching establishes attribution, not scientific truth. The full independent source review still checks every clause, equation, result condition, calculation and quiz answer against the primary evidence. A compound claim with inadequate support must be narrowed or recited to an available supporting primary source. Changing a statement, condition or citation triggers a new passage-selection step before review; unchanged ledger statements retain their bindings. This addresses repeated malformed and unrelated quote repairs without weakening any source or publication gate.

For an existing withheld candidate, `--resume-defects --select-evidence` starts a bounded evidence-selection and review phase on its preserved original prose, followed by at most four targeted scientific repairs. This flag does not publish failures or overwrite a reviewed lesson. Selection prompts contain public paper excerpts and original educational drafts only; ignored audit storage is not an owner-document input. The private range record includes its passage-generator version and source-excerpt digest and is never included in the public lesson JSON. Transport initialization failures stop that lesson without consuming scientific-repair attempts; they remain private diagnostics. Relevant scientific limits belong at the affected teaching point, rather than in repetitive warnings or narration about extraction coverage.

## PDF inclusion placeholders and source scope

The full-library source audit found a second arXiv representation issue: some HTML pages contain only a LaTeXML inclusion pointer such as `See pages 1-last of 0_adam_main.pdf`. Counting that pointer as a second citation incorrectly labeled abstract-only evidence as full text and skipped the primary-PDF fallback. The extractor now removes these inclusion pointers; full-text acquisition requires at least 400 characters of non-abstract scientific body excerpts, excluding truncation markers. This bounded threshold is an acquisition check, not proof of a scientific claim; independent source review remains mandatory. PDF fallback applies the same body requirement.

The audit scanned all cached root and refinement contexts. It identified Adam, PPO, and Rethinking Generalization as placeholder-only. The affected Generalization publication was withheld only after confirming its current review fingerprint and exact source digests matched that deficient context; its bytes and audit reason are preserved privately. Valid lessons remained available. Affected contexts require refresh from public primary PDFs using an existing bundled Python runtime, without installing dependencies, followed by fresh original drafts and all review gates. Generation proceeds only after the corrected evidence is available. Existing paper kits and production workers are not silently migrated.

The explicitly approved NeRF upgrade replaces its Gaussian-footprint analogy with the tested four-interval volume-rendering recurrence in section 3. Its constructed densities/colors, opacity weights, prefix transmittance and finite-ray white-background term are taught in the lesson itself. The source-gated figure review passed; primary claim identities and actual source URLs/excerpt digests stayed unchanged. The parent publication fingerprint changed because the prose/figure and source-version/capture metadata changed, so any earlier mechanism sidecar remains unavailable until reviewed against that new parent. Browser acceptance is a separate release check.

The subsequent relevance audit identified numerical prerequisites that distracted from their papers' central mechanisms. SmoothQuant now replaces its standardization contrast with paired channel scaling in section 3: activation columns divide by the channel scale, matching weight rows multiply by it, and the exact unquantized matrix product stays fixed. Mistral replaces allocation padding with a causal rolling-cache trace in section 4. Its declared read-before-write instance stores four previous tokens and holds the current key/value separately, preserving the primary paper's inclusive `i−W…i` eligibility rule before the modular cache write. Neither construction converts its chosen inputs into measured paper results. Both replacements passed independent source, teaching, experiment, math, and quiz checks before local publication.

Chain of Thought's unrelated breadth-first search and invented power-law figures were removed through explicit editorial review; the lesson explains the demonstrated input→intermediate-text→answer intervention and keeps the paper's scale-dependent results attached to their actual evaluation conditions. VGG's unrelated patch-mask figure was removed, with its architecture, receptive-field progression, pooling, optimization and preprocessing explained directly. Selected closing sections were reviewed again to replace extraction-coverage narration with scientific interpretation. The same primary claim identities, exact private evidence, source URLs, and excerpt digests were retained. See [the bounded relevance audit](subject-figure-relevance-audit-2026-10-01.md) for remaining candidates; browser acceptance and any mechanism sidecar re-review remain separate.

## Reviewing explicitly authored corrections

`scripts/review-subject-candidate.ts` reviews one complete original candidate from that lesson's ignored audit directory. It defaults to a private reviewed result; `--publish` enables local publication after all source, math, teaching, experiment and quiz checks pass. It may use an explicitly supplied expanded primary context, retaining each existing source identity, URL and excerpt digest. Only bounded excerpts from the catalog entry's exact public arXiv paper enter the review payload, alongside original teaching and declared experiment/mechanism contracts. Owner documents, database snapshots and credentials are outside this input contract. The model transport still requires the applicable destination authorization.

The helper permits an initial review and at most four targeted repairs. Scientific statement or citation changes trigger exact primary-passage selection again. Publication rejects concurrent changes to the parent lesson, primary contexts, mechanism sidecar or rendering implementation. A prose correction with unchanged source and claim identities may rebind the existing source-reviewed mechanism, always resetting its visual approval. Changed claims or expanded sources leave the earlier sidecar unavailable until reviewed against the new parent. Explicit figure removals clear only the corresponding section anchors; candidates still need the full review before becoming readable.

For example, prepare a candidate privately and run:

```sh
node --import tsx scripts/review-subject-candidate.ts \
  --id <catalog-id> \
  --candidate .artifacts/subjects/<catalog-id>/<candidate>.json
```

Selected prose cleanup preserves claims, citation identities, figure contracts and quiz answers. Its purpose is to replace extraction narration with the actual method, mathematical assumptions and experimental conditions. If the scientific explanation requires a missing appendix or central section, capture that public primary material and review the expanded candidate rather than deleting the necessary qualifier.

`scripts/clean-subject-narration.ts --run --concurrency 2` applies this workflow to the explicitly classified editorial set, excluding independently owned mechanism priorities, Whisper and three primary-source expansions. `--audit` accepts an explicitly selected private editorial manifest, and `--id` limits the run to one identity in that assigned set. It includes affected figure chapters with repetitive capability inventories. Authored edits may alter selected Markdown only, followed by a complete independent candidate review. Source or scientific defects remain failures until a supported bounded correction passes. Private status projections distinguish pending, editing, reviewing, published, already-clean and failed identities; existing reviewed lessons remain available while a replacement fails or runs. This workflow is an explicitly invoked local content correction, never an automatic page-load or worker job.

Private ledger restoration now accepts the already-bound primary context and chooses an unchanged claim only when its saved evidence is a literal passage in that claim's declared excerpts. It skips normalized quote strings, such as versions with extraction markers removed, and can recover the exact unchanged evidence from an earlier private candidate. It never reconstructs a quotation from normalized prose and fails closed when no literal record matches. The prose refiner, mechanism generator and narration cleanup pass their bound context into this check. KaTeX failures also identify the specific rendered field so targeted repairs need not rewrite unrelated sections. An inadequate local anchor can trigger deterministic passage reselection from the same cited primary sources; scientific review still checks the entire statement and its conditions.

The initial editorial phase locally published 43 reviewed corrections and skipped the already-clean Whisper parent. Six candidates were preserved through failed local checks and recovered with full independent review, rather than exposing their failed drafts. A separate VAE correction removed the unrelated norm and quadratic-optimizer controls and taught the reparameterized ELBO computation directly. Three additional residual reviews cleaned the score-matching, LayerNorm and imaging-tutorial lessons. Fresh reviews also corrected scientific conditions, including guided-DDIM scale, the proper scope of Diffusion Policy's reported improvement, Mistral's inclusive-window quiz, finite-schedule Gaussian approximation and the sphere-coordinate density domain. This content milestone does not grant visual approval to a changed mechanism or establish comparative superiority over the reference site.
