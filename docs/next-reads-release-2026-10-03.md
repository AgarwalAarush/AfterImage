# Next reads production release

PR [#11](https://github.com/AgarwalAarush/AfterImage/pull/11) was squash-merged into `main` at `70fdb29d22bcef0d5b9b20e90192924400c228ce`. Vercel deployment `dpl_EuDKYz6pEX6qNpRXeKPyXViAC5HD` was built from that exact commit, checked before promotion, and verified at [AfterImage](https://afterimage.aarushagarwal.dev). The release includes the previously merged reader controls from PR #10. Vercel has no Git integration for this project, so merge and deployment were separate operations.

Saving or preparing a suggestion commits it to Library and removes it from Next reads. Dismiss records negative feedback without saving the paper. These actions queue one bounded refill that preserves the other suggestions. Explicit Refresh suggestions replaces the shortlist. The visible dismiss control replaces the redundant save/checkmark; Save for later remains in the feedback menu. Ranking combines relevance, next-step usefulness and bounded verified citation influence. See [the behavior and ranking contract](next-reads-advancement-2026-10-03.md).

The compatible web/API was promoted first. During release, the production generation worker advanced from generation-v14 to generation-v15; the discovery overlay was rebuilt on generation-v15 and revalidated instead of downgrading those fixes. The active release is `AfterImage-worker-20261003-nextreads-v2`. Its generation and study functions, dependency lock and environment match generation-v15 byte for byte. Graceful drain preserved active work before activation. The storage bridge, Cloudflare Access transport, authentication, SQLite schema and assistant worker were unchanged.
