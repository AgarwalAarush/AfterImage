# Scientific SVG animation

Use [scientific-diagrams](../scientific-diagrams/SKILL.md), then its [animation mode](../scientific-diagrams/references/animation.md). Read both before authoring. This entry point preserves existing invocations; all scientific, design, and review guidance belongs to the shared diagram skill.

Use the canonical skill's examples, scripts, and render-review-repair loop. Do not copy or maintain another renderer, rubric, typography system, or generation pipeline here. Installing these skills does not enable automatic animations in AfterImage's worker.
